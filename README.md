# Radar Tech · Javier Rodriguez

Sitio personal de vigilancia tecnológica docente.

## Publicación

El repositorio incluye un workflow de GitHub Pages en `.github/workflows/pages.yml`.

1. En Settings → Pages, seleccionar **GitHub Actions** como fuente.
2. Hacer push a `main`.

## Actualización de contenido

Las noticias viven en `data.json`. Cada nueva ejecución del radar puede agregar objetos al array `items`, actualizar `top3` y la fecha `updated`.
